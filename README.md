# 🐾 PEAT — Pet Shop Online Oficial com Avaliações (Reviews)

Projeto de e-commerce completo, responsivo (**Mobile-First**), com catálogo oficial de 9 produtos pet, preços competitivos e **sistema completo de avaliações (reviews)** com estrelas e depoimentos verificados de clientes.

---

## ⚡ Stack Tecnológica (100% Gratuita)

| Camada | Tecnologia | Descrição |
|---|---|---|
| **Frontend** | HTML5 + Tailwind CSS (CDN) + Vanilla JS (ES6+) | Interface moderna com estrelas interativas, formulário de reviews e carrinho |
| **Backend / APIs** | Vercel Serverless Functions (Node.js) | Endpoints serverless para cálculo de frete, geração de PIX, webhooks e reviews |
| **Banco de Dados** | Supabase (PostgreSQL + RLS) | Tabelas `produtos`, `avaliacoes` e `pedidos` com Row Level Security ativo |
| **Pagamentos** | Mercado Pago API | Geração de PIX com QR Code dinâmico, código "Copia e Cola" e Cartão |
| **Logística / Frete** | Melhor Envio API | Cálculo automático de CEP com cotação PAC e SEDEX |

## ⭐ Sistema de Avaliações (Reviews)

1. **Exibição nos Cards da Vitrine:**
   - Estrelas amarelas (`★★★★★`), média numérica (ex: `4.9`) e total de opiniões entre parênteses `(14)`.
2. **Modal de Detalhes:**
   - **Resumo Destacado:** Nota média em destaque com estrelas e total de opiniões.
   - **Lista de Avaliações Recentes:** Depoimentos de exemplo com nome do cliente, estrelas, selo "Compra Verificada" e comentário.
   - **Formulário de Nova Avaliação:**
     - Seletor de estrelas interativo (1 a 5).
     - Nome do cliente e Comentário.
     - Persistência imediata no `localStorage`, endpoint `/api/avaliacoes` e tabela `avaliacoes` do Supabase.
     - Recálculo dinâmico da média e atualização da vitrine em tempo real sem recarregar a página!

## 🗄️ Tabela de Avaliações no Supabase

Execute o script [`supabase_schema.sql`](supabase_schema.sql) no SQL Editor do seu projeto Supabase:

```sql
CREATE TABLE public.avaliacoes (
  id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  produto_id INT REFERENCES public.produtos(id) ON DELETE CASCADE,
  nome_cliente VARCHAR(100) NOT NULL,
  nota INT CHECK (nota >= 1 AND nota <= 5),
  comentario TEXT,
  criado_em TIMESTAMP WITH TIME ZONE DEFAULT NOW()
);
```
